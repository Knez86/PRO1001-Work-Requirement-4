# Product Rating Dashboard

A responsive product ratings dashboard developed for Work Requirement 4 in Frontend Essentials.

## Project Overview

The dashboard retrieves product information from the Fake Store API and uses Highcharts to visualize customer ratings.

## Features

- Dynamic data retrieval from an external API.
- Overview of total products, average rating and product categories.
- Column chart displaying average ratings by category.
- Horizontal bar chart displaying the five highest-rated products.
- Loading and error handling.
- Responsive layout.
- Keyboard navigation and Highcharts accessibility support.

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Highcharts
- Git and GitHub

## Running the Project

Clone the repository and open `index.html` using a local development server, such as Live Server in Visual Studio Code.

An internet connection is required to retrieve product data and load Highcharts.
